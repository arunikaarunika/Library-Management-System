📚 LIBRARY MANAGEMENT SYSTEM

📌 PROJECT OVERVIEW :

The Library Management System is a simple web-based application developed using Java, Servlets, and JDBC. It provides a basic digital solution for storing and viewing book records instead of maintaining manual registers.
This project demonstrates the core concepts of Java Web Development, database connectivity, and request–response handling using the Apache Tomcat server. It follows a structured approach to handle client requests, process data, and interact with a relational database efficiently.

✨ FEATURES :

➕ Add Book
Allows users to enter book details such as ISBN, Title, Author, and Price through a form. The data is processed by a Servlet and stored in the database using JDBC insert operations.

📖 View Books
Displays all stored books in a table format on a web page. This module retrieves data from the database using SELECT queries and dynamically shows it to the user.

🛠 TECHNOLOGIES USED :

☕ Java – Core application logic

🌐 Servlets – Handle client requests and responses

🔗 JDBC – Database connectivity and SQL operations

🎨 HTML / CSS – User interface design

🖥 Apache Tomcat – Server for deployment

🗄 Oracle – Database for storing book data
